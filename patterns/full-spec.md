# パターンA: 王道フルスペック型

最も多くのサイトが採用する「教科書的」な構成パターンです。ヒーローセクションから始まり、サービス概要や機能紹介で製品を理解してもらい、導入事例や実績で信頼を積み上げ、サポート情報やお役立ちコンテンツを経てページを締めくくります。B2Bトップページの王道とも言える構成で、日本市場の国産SaaSに特に多く見られます。

**22サイト（全体の37.3%）** / 平均セクション数: 10.2

## 主な特徴

- ヒーローからCTAまで、**必要な情報を漏れなく配置**する網羅型の構成
- 導入事例・実績紹介で**信頼構築に注力**している
- ニュース、お役立ち資料、サポート情報など**コンテンツマーケティング導線が充実**
- CTAはページ末尾に配置し、**十分な情報提供の後に行動を促す**設計
- セクション数は10前後と**ボリュームがある**

## 典型的なセクションの流れ

> ヒーロー → サービス概要 → 機能紹介 → 選ばれる理由 → 導入事例 → 料金 → サポート → お役立ち資料 → ニュース → CTA

## このパターンが向いているケース

**サービスの特性:**
- 複数の機能や製品ラインナップを持つ総合的なサービス
- 導入実績が豊富で、事例を通じた訴求が効果的なサービス
- サポート体制や導入支援の充実度がアピールポイントとなるサービス

**ターゲットユーザーの特徴:**
- 慎重に情報収集を行い、十分に納得してから問い合わせる傾向のある担当者
- 社内稟議を通す必要があり、多角的な判断材料を求めている検討者

**市場環境:**
- コンテンツマーケティング（セミナー、ホワイトペーパー等）が有効な市場
- 「まず情報を得たい」というフェーズのユーザーが多い市場

国産SaaSに特に多いこのパターンは、日本市場における「情報提供型マーケティング」の重要性を反映していると言えます。ニュースやお役立ち資料への導線を充実させることで、すぐにはコンバージョンしないユーザーとの接点を維持する設計思想が見て取れます。
