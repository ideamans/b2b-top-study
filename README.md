# B2Bトップページ研究

B2B SaaSサービスサイトのトップページ構成を横断的に分析した調査レポートの公開サイトです。

## 概要

国内外のB2B SaaSサービス62サイトのトップページを対象に、ページを構成するセクションを1つずつ分解・分類しました。合計563セクションを34種類のタグに整理し、各セクションの採用率やページ内の配置位置を定量的に分析しています。

## コンテンツ構成

- **調査概要** (`overview.md`) - 調査の目的・方法・主な発見
- **典型的なページ構成の流れ** (`flow.md`) - B2Bトップページの一般的な構成順序
- **調査手法・対象サイト** (`about.md`) - 調査方法と対象62サイトの一覧

### 構成パターン（類型）

クラスタリング分析により分類した6つのトップページ構成パターン:

- 王道フルスペック型
- 網羅フルコース型
- 実績訴求・多機能型
- 価値提案・CTA直行型
- 料金・比較検討促進型
- コミュニティ・ブランド型

### セクション別ガイド

34種類のセクションについて、採用率・配置位置・スクリーンショット付き実例を掲載:

- ヒーローエリア、サービス概要、価値訴求、課題解決、機能紹介
- 導入実績・数値、導入企業ロゴ、導入事例、お客様の声
- サポート体制、導入の流れ、よくある質問
- CTA、お役立ち資料、お知らせ、セミナー・イベント など

### ヒーロー深掘り

ファーストビューのキャッチコピーパターンを分析。

## 技術スタック

## 開発

```bash
# 依存パッケージのインストール
yarn install

# 開発サーバーの起動
yarn dev

# ビルド
yarn build

# ビルドのプレビュー
yarn preview
```
